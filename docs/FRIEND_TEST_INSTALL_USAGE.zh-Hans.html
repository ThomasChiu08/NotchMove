NotchMove 测试版安装与使用说明

这份说明面向帮忙测试 NotchMove 的朋友。当前 DMG 是测试包，不是面向公开分发的正式 notarized 版本，所以首次打开时 macOS 可能会额外确认。

支持 Apple Silicon 和 Intel Mac。当前项目的部署目标是 macOS 14.0，系统版本低于 macOS 14.0 时可能无法启动。

安装

  1. 打开 NotchMove-*.dmg。
  2. 把 NotchMove.app 拖到 Applications 文件夹。
  3. 从 Applications 打开 NotchMove。建议首次打开时右键点击 NotchMove.app，选择“打开”，再在弹窗中确认。
  4. 启动后在菜单栏找到走路图标，点击图标即可看到 NotchMove 菜单。
如果 macOS 提示无法验证开发者，进入“系统设置 > 隐私与安全性”，在页面底部点击“仍要打开”。

如果仍提示文件已损坏，只在确认 DMG 来源可信时打开“终端”运行：

xattr -dr com.apple.quarantine /Applications/NotchMove.app

然后重新打开 NotchMove。

更新旧测试版

  1. 点击菜单栏 NotchMove 图标，选择“退出 NotchMove”。
  2. 打开新版 DMG，把新版 NotchMove.app 拖到 Applications。
  3. macOS 询问是否替换时选择“替换”。
  4. 重新打开 NotchMove。

如果之前测试过缺少麦克风权限声明的旧包，退出 NotchMove 后可以运行：

tccutil reset Microphone com.thomaschiu.developer.NotchMove

之后重新打开 NotchMove，并在“控制台 > AI 助手”里重新请求麦克风权限。

基本使用

NotchMove 启动后会常驻菜单栏。点击走路图标可以：

  • 查看下次站立提醒、今天和本周的休息次数、下一项日程。
  • 选择“暂停提醒”或“恢复提醒”。
  • 选择“立即提醒”手动触发一次刘海或居中浮层提醒。
  • 打开“AI 添加日程...”录入日程。
  • 开关“提醒声音”。
  • 打开“控制台...”管理今天、日程、休息记录和设置。
  • 选择“退出 NotchMove”完全退出应用。

控制台

“控制台”左侧分为“工作区”和“设置”。

  • “今天”：查看当前追踪状态、下一次站立提醒、当前或下一项日程；也可以立即提醒、新增日程或使用语音添加日程。
  • “日程”：新增、编辑、导入或清空今天的日程。日程可以设置开始/结束时间、提前提醒和备注。
  • “休息”：查看今天和本周完成的休息次数。
  • “提醒”：设置提醒间隔、久坐感知模式、工作时间和工作日限制。
  • “AI 助手”：启用语音添加日程，选择转写和解析服务，保存 API Key，请求麦克风或语音识别权限。
  • “行为”：设置提醒显示屏幕、刘海展开、悬停预览、声音、自动关闭时间。
  • “语言”：切换 English、简体中文、繁体中文或日文。
  • “启动”：设置是否登录后自动启动。

AI 添加日程

如果只测试站立提醒和手动日程，不需要配置 AI。要测试语音添加日程：

  1. 打开“控制台 > AI 助手”。
  2. 开启“启用 AI 助手”。
  3. 选择转写服务和解析服务。
  4. 按界面提示保存对应 API Key。密钥会存进 macOS 钥匙串。
  5. 点击“请求权限”允许麦克风权限；如果使用 Apple Speech，还需要允许语音识别权限。
  6. 回到菜单栏选择“AI 添加日程...”，或在“今天/日程”页面点击“语音”。
  7. 录音后检查识别出的草稿，确认无误再添加到今天的日程。
选择云端服务时，音频或转写文本可能会发送给所选服务商；选择本地转写时，音频会留在本机，但解析日程时转写文本仍可能发送给解析服务商。

测试反馈

反馈问题时请尽量包含：

  • macOS 版本和 Mac 型号。
  • 使用的是哪个 DMG 文件名。
  • 问题发生在哪一步。
  • 预期结果和实际结果。
  • 截图或录屏。
  • 如果是 AI 功能问题，请说明使用的转写服务和解析服务，不要发送 API Key。

卸载

  1. 点击菜单栏 NotchMove 图标，选择“退出 NotchMove”。
  2. 删除 /Applications/NotchMove.app。
  3. 如果开启过登录启动，建议先在 NotchMove 的“启动”设置里关闭，或到“系统设置 > 通用 > 登录项”里移除。
