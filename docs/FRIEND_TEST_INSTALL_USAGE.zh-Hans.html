NotchMove 测试包说明

安装、授权和日常使用

NotchMove 是原生 macOS 菜单栏应用，用刘海区域或顶部浮层提醒你站立、活动，也支持本地日程提醒和可选 AI 语音录入。

当前测试包面向朋友测试。首次打开时，macOS 可能需要你手动确认来源和权限。
安装 更新旧版本 基本使用 控制台 AI 语音日程 反馈与卸载

安装

  1. 打开 NotchMove-*.dmg。
  2. 把 NotchMove.app 拖到 Applications 文件夹。
  3. 从“应用程序”打开 NotchMove。首次打开建议右键点击 NotchMove.app，选择“打开”，再确认。
  4. 启动后，在菜单栏找到 NotchMove 图标，点击图标即可打开菜单。
如果 macOS 提示无法验证开发者，进入“系统设置 > 隐私与安全性”，在页面底部点击“仍要打开”。

如果提示文件已损坏

只在确认 DMG 来源可信时打开“终端”运行下面命令，然后重新打开 NotchMove。

xattr -dr com.apple.quarantine /Applications/NotchMove.app

更新旧测试版

  1. 点击菜单栏 NotchMove 图标，选择“退出 NotchMove”。
  2. 打开新版 DMG，把新版 NotchMove.app 拖到 Applications。
  3. macOS 询问是否替换时选择“替换”。
  4. 重新打开 NotchMove。

如果旧包曾缺少麦克风或语音识别权限声明，可以退出 NotchMove 后重置权限记录。

tccutil reset Microphone com.thomaschiu.developer.NotchMove
tccutil reset SpeechRecognition com.thomaschiu.developer.NotchMove

基本使用

NotchMove 启动后会常驻菜单栏，不显示 Dock 图标。点击菜单栏图标可以执行这些常用操作：

查看状态查看下次站立提醒、今天和本周休息次数、下一项日程。
控制提醒暂停/恢复提醒，或手动触发一次刘海/居中浮层提醒。
录入日程打开“AI 添加日程…”或进入控制台手动新增、导入日程。
调整行为开关提醒声音，进入控制台调整提醒间隔、工作时间和显示位置。

控制台

菜单栏选择“控制台…”后，可以在左侧切换“工作区”和“设置”。

  • “今天”：查看当前追踪状态、下一次站立提醒、当前/下一项日程，也可以立即提醒或新增日程。
  • “日程”：新增、编辑、导入或清空今天的日程。日程支持开始/结束时间、提前提醒和备注。
  • “休息”：查看今天和本周完成的休息次数。
  • “提醒”：设置提醒间隔、久坐感知模式、工作时间和工作日限制。
  • “行为”：设置提醒显示屏幕、刘海展开、悬停预览、声音和自动关闭时间。
  • “语言”：切换 English、简体中文、繁体中文或日文。
  • “启动”：设置是否登录后自动启动。

AI 语音日程

如果只测试站立提醒和手动日程，不需要配置 AI。要测试语音添加日程：

  1. 打开“控制台 > AI 助手”。
  2. 开启“启用 AI 助手”。
  3. 选择转写服务和解析服务。
  4. 按界面提示保存对应 API Key。密钥会存进 macOS 钥匙串。
  5. 点击“请求权限”允许麦克风权限；如果使用 Apple Speech，还需要允许语音识别权限。
  6. 回到菜单栏选择“AI 添加日程…”，或在“今天/日程”页面点击“语音”。
  7. 录音后检查识别出的草稿，确认无误再添加到今天的日程。
选择云端服务时，音频或转写文本可能会发送给所选服务商；选择本地转写时，音频会留在本机，但解析日程时转写文本仍可能发送给解析服务商。

反馈与卸载

测试反馈

  • macOS 版本和 Mac 型号。
  • 使用的 DMG 文件名。
  • 问题发生在哪一步。
  • 预期结果和实际结果。
  • 截图或录屏。
  • 如果是 AI 功能问题，请说明使用的转写服务和解析服务，不要发送 API Key。

卸载

  1. 点击菜单栏 NotchMove 图标，选择“退出 NotchMove”。
  2. 删除 /Applications/NotchMove.app。
  3. 如果开启过登录启动，建议先在 NotchMove 的“启动”设置里关闭，或到“系统设置 > 通用 > 登录项”里移除。
