## 本次发布内容

- 重新设计 DMG 背景图，视觉风格与 NotchMove 图标保持一致。
- 新增 `NotchMove-Install-Usage-zh-Hans.html`，用于离线查看安装、权限、日常使用、AI 日程和卸载说明。

- 打包脚本会优先使用 Developer ID Application 签名；本机没有 Developer ID 时，自动降级为 Apple Development 测试签名。

## 安装方式

1. 下载并打开 `NotchMove-1.0-test-*.dmg`。
2. 将 `NotchMove.app` 拖到 `Applications`。
3. 从“应用程序”打开 NotchMove。首次打开建议右键选择“打开”。
4. 如 macOS 提示无法验证开发者，到“系统设置 > 隐私与安全性”确认打开。

## 已知分发限制

本次包是测试分发包。如果构建机没有 Developer ID Application 证书，DMG 会使用 Apple Development 签名，并且不会 notarize。公开分发正式版本前，需要使用 Developer ID Application 证书重新打包，并设置 `NOTARIZE=1` 完成 notarization 和 stapling。
